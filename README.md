# QA-QualityWorkers

## Proyecto de pruebas de software — CampoClaro

Repositorio académico correspondiente a la asignatura Pruebas de Software y Herramientas Avanzadas de Desarrollo.

## Integrantes

- Ana Judith Velasquez
- Maria del Mar Perez
- David Segundo Giron

## Objetivo

Diseñar, implementar y ejecutar pruebas de software sobre el sistema CampoClaro, con el propósito de evaluar su comportamiento funcional, la lógica de sus componentes y su eficiencia de desempeño.

## Sistema objeto de pruebas

CampoClaro es una aplicación web orientada a la gestión del rodeo bovino y al seguimiento de indicadores reproductivos y productivos.

Repositorio original: https://github.com/cghidalgos/vaky

El código fuente original se mantiene en un repositorio independiente. Este repositorio contiene los recursos desarrollados por el equipo para el proceso de pruebas de software.

## Alcance

- Gestión del rodeo bovino.
- Clasificación del riesgo reproductivo.
- Consulta de indicadores generales.
- Importación y exportación de información mediante archivos CSV.

## Herramientas

| Herramienta | Propósito |
| --- | --- |
| Pytest | Pruebas unitarias |
| Pytest-cov | Cobertura de código |
| Playwright | Automatización de pruebas funcionales |
| Apache JMeter | Pruebas de rendimiento y carga |
| Git y GitHub | Control de versiones y trabajo colaborativo |
| GitHub Actions | Integración y despliegue continuo |
| Docker | Preparación del entorno de pruebas |
| Jira | Gestión y seguimiento de actividades |
| Confluence | Documentación del proceso de pruebas |

## Trabajo colaborativo

- `main`: versión estable del proyecto de pruebas.
- `develop`: integración de los avances del equipo.
- Ramas de trabajo: desarrollo de actividades específicas.

La integración de cambios se realiza mediante Pull Requests y revisión de las contribuciones.
